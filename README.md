# C++ Football Pack Opening Simulator

A console-based football pack-opening simulator developed in 2024 as a university assignment.

The main goal of the project was to demonstrate a practical application of an **AVL tree** data structure. I chose to build a football-themed pack-opening game to make the assignment more engaging.

The project also provided an opportunity to practice **object-oriented programming in C++**, which I was learning at the time.

## Main Components

- **AVL Tree:** Implementation of a self-balancing binary search tree.
- **Football Players:** Representation of football player cards within the game.
- **Console Interface:** Terminal-based visualization and interaction.

## Technologies and Concepts

- C++
- Object-Oriented Programming (OOP)
- AVL Trees
- Data Structures and Algorithms
- Console Applications
